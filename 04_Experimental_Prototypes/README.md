# Experimental Prototypes
**Status:** Research Grade / Sandbox

These scripts isolate specific mechanisms of the theory:
*   **`est_gravity_lensing.py`:** A pathfinding algorithm showing how light avoids high-complexity regions.
*   **`est_mass_inertia.py`:** A Ternary automata showing how neighbor pressure creates "Mass" and "Inertia."
*   **`est_time_thermo.py`:** A high-constraint simulation showing the asymptotic behavior of time.
*   **`est_Relational_Engine.py`:** A graph-based solver that abandons the fixed lattice. Demonstrates the emergence of spherical lightcones and Lorentz Invariance from causal connectivity alone.
